# AGENTS.md

## Scope
These instructions apply to the whole repository.

## Base Guidelines
- Start by proposing a short plan before making changes.
- Ask for confirmation before doing substantive work.
- Do not assume permission to edit files, run notebooks, or modify data without explicit user approval.
- If the request is ambiguous, clarify the target notebook or file first.
- Prefer the simplest solution that correctly solves the task.
- Keep each change properly organized, with clear structure and separation of concerns.
